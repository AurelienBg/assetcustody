# Asset Custody — The XRPL Triad

A pedagogical sheet on the **Ownership · Custody · Possession** triad
applied to XRPL, designed for entrepreneurs discovering tokenization.

Covers the founding distinction between an **asset** and its **digital
representation**, the three layers of control, the configuration matrix,
the XRPL primitives that maintain alignment (trustlines, credentials,
freeze, clawback, MPT, permissioned domains), the regulatory burden per
layer, and a token qualification tree (MiCA / US).

Available in **French** and **English** — language toggle in the top-right
corner.

Une fiche pédagogique sur la triade **Ownership · Custody · Possession**

couche, et un arbre de qualification du token (MiCA / US).
